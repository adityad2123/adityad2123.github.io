I've consolidated my code into main.py per the submission instructions,
though I think it's far more effective if just run as separate files,
so I attached those as well. You can run either the main.py file or each separate file for each part.

Part 1 -> out_p1
Part 2.1 -> out_p2
Part 2.2 -> out_hybrid
Part 2.3/4 -> out_multi.
